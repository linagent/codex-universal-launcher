# Brand asset generation prompts

The three PNG concepts in this directory were generated with the built-in OpenAI image-generation tool. They are original project assets and deliberately avoid OpenAI's swirl or other third-party logos.

## Primary: verified network tunnel

```text
Use case: logo-brand
Asset type: primary app icon and GitHub project mark for an open-source Windows utility named Codex Universal Launcher
Primary request: create one original, compact symbol that communicates a safe, verified network route before application launch
Subject: a rounded shield-like gateway containing a clean forward connection path made of three linked nodes, subtly suggesting routing and stability
Style/medium: polished vector-friendly flat icon, geometric, modern Windows utility aesthetic, excellent silhouette at 32px
Composition/framing: single centered icon, generous transparent padding, square canvas
Color palette: deep cobalt blue, bright cyan accent, small mint-green verified accent; balanced dark and light contrast
Constraints: genuinely transparent background; no words, no letters, no OpenAI swirl, no third-party logos, no gradients that disappear at small sizes, no mockup surface, no watermark
Avoid: padlocks, robot faces, speedometer, excessive detail, 3D perspective, glow haze
```
