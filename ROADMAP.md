# Roadmap

## Near term

- Collect redacted compatibility reports for more PAC and authenticated-proxy environments.
- Add a first-class restore UI for the latest environment backup.
- Add English UI localization while keeping Chinese as a supported language.
- Improve proxy-engine identification without expanding write permissions.

## Later

- Optional portable diagnostics bundle with explicit user review before export.
- Signed Windows releases when a sustainable code-signing path is available.
- Additional tests for unusual IPv6, enterprise proxy, and multi-provider configurations.

Non-goals include managing proxy subscriptions, changing nodes, bypassing organizational policy, altering system security settings, or promising that every reconnect is network-related.
